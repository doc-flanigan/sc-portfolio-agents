# sc-portfolio-agents

Shared Claude Code subagents for the **o7citizen.com Star Citizen fan-site network** by Doc_Flanigan.

This repo is the version-controlled source of truth for agents that live in `~/.claude/agents/`. Edit here, sync, commit.

## Agents

| Agent | Purpose |
|---|---|
| [`agents/sc-news.md`](agents/sc-news.md) | Writes the weekly Star Citizen plain-English digest for o7citizen.com. Pulls from official RSI Comm-Links and CIG-staff Spectrum posts only. |
| [`agents/sc-fact-check.md`](agents/sc-fact-check.md) | Audits factual claims on any SC fan-site (or draft article) against official Cloud Imperium sources only. Returns ✅ / ⚠️ / ❌ / ❓ verdicts with source URLs. |

## Workflow

The canonical edits happen in this repo. The deployed copies in `~/.claude/agents/` are produced by a sync script — never edit them directly.

```
sc-portfolio-agents/agents/*.md   ←  source of truth (edit here)
~/.claude/agents/*.md             ←  deployed copies (regenerated by sync)
```

### First-time setup

Clone this repo somewhere stable (alongside your other SC repos works fine):

```bash
git clone https://github.com/doc-flanigan/sc-portfolio-agents.git
cd sc-portfolio-agents
```

Then run the sync script appropriate for your shell:

```bash
# bash / git bash / WSL / macOS / Linux
./sync.sh

# Windows PowerShell
./sync.ps1
```

The sync copies every `agents/*.md` into `~/.claude/agents/`, overwriting any existing file with the same name.

### Editing an agent

1. Edit the file under `agents/` in this repo
2. Run `./sync.sh` (or `./sync.ps1`) to push the change into `~/.claude/agents/`
3. Test in a Claude Code session
4. Commit and push from this repo when you're happy

### Pulling updates on another machine

```bash
git pull
./sync.sh   # or ./sync.ps1 on Windows
```

## Why a separate repo

Earlier in the network, agents lived inside individual product repos (e.g. `o7citizen-main/.claude/agents/sc-news.md`). That created drift across eight repos and noise in product diffs. They were moved to user-scope (`~/.claude/agents/`), which solved drift but lost version history.

This repo splits the difference: one source of truth, one place to edit, simple deploy step into user-scope so every Claude Code session in any portfolio repo picks the agents up automatically.
